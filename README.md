# Noweix HUB

Le site de Noweix HUB, avec Nojah (order flow) et Weizix (ICT) : https://azulixnq.github.io/nojah/ (le lien n'a pas changé).

- `index.html` : la page (le style et le script sont dedans, aucun service extérieur).
- `img/certificats/` : les 11 certificats de payout Lucid Trading de Nojah, recadrés depuis ses captures (aucun n'est refait).
- `video/` : l'épisode 1 de la série de Nojah (l'absorption, nouveau style) et son affiche.
- `fonts/` : la police du site (licence SIL Open Font License 1.1, voir `fonts/OFL.txt`).
- `og.jpg` : l'image qui s'affiche quand on partage le lien. `favicon.svg` et `apple-touch-icon.png` : les icônes.
- `apercu/` : l'ancien lien de l'aperçu, qui renvoie vers la page.

Mise en ligne : GitHub Pages, branche `main`, dossier racine.
